Fan Hub

Plataforma Flutter multi-clube: uma base compartilhada que opera como apps independentes, cada um com identidade, conteúdo e funcionalidades próprias. Hoje, com experiências dedicadas ao Goiás e ao RB Bragantino.

Android iOS Web / PWA Flutter Supabase
Privacidade — Goiás EC Privacidade — RB Bragantino
Flavor Goiás

A experiência do torcedor

A partir de uma base compartilhada, o flavor do Goiás reúne o dia a dia do torcedor: jogo, clube, interação e conteúdo em um só app.

Telas reais

O app em uso

Arquitetura

Um código-base, vários clubes

O desafio é evoluir um único código-base para múltiplos clubes sem que features, dados ou identidade visual de um vazem para o outro. A solução é uma arquitetura club-scoped da camada de domínio à de dados, com a configuração do clube injetada na inicialização (via flavor) e isolamento real no Supabase — cada clube com seu próprio projeto e políticas de RLS dedicadas.

Núcleo compartilhado — Flutter · Clean Architecture · Arena engine · Design system
