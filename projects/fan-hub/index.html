Fan Hub

Uma base Flutter multi-clube: um único produto capaz de operar como aplicativos independentes para diferentes clubes de futebol, cada um com identidade visual, conteúdo e funcionalidades próprias — sem duplicar o código-base.

Android iOS Web / PWA Flutter Supabase
Política de Privacidade do app

Visão do produto

O Fan Hub nasceu da ideia de que a experiência digital de um torcedor — partidas, conteúdo, jogos e presença no clube — pode ser construída sobre uma base técnica compartilhada, sem que cada clube exija um app completamente novo do zero. Hoje o Fan Hub roda em produção com flavors para o Goiás e o RB Bragantino.

Desafio arquitetural

O núcleo do desafio é manter um único código-base evoluindo para múltiplos clubes sem que features, dados ou identidade visual de um clube vazem para o outro. Isso exigiu uma arquitetura club-scoped desde a camada de domínio até a camada de dados, com configuração de clube injetada na inicialização do app (via flavor) e isolamento real dos dados no Supabase — cada clube com seu próprio projeto e políticas de RLS dedicadas.

Núcleo compartilhado — Flutter · Clean Architecture · Arena engine · Design system
