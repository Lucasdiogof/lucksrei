Fan Hub

A Flutter app dedicated to Goiás fans, with its own identity, content and features, built on a club-scoped architecture.

Android iOS Web / PWA Flutter Supabase
Privacy — Goiás EC
Goiás flavor

The fan experience

Built on a shared codebase, the Goiás flavor brings together the fan's day to day: matches, club, interaction and content in a single app.

Real screens

The app in use

Architecture

Club-scoped architecture

The app is built on a club-scoped architecture from the domain layer to the data layer, with the club configuration injected at startup (via flavor) and real isolation in Supabase — a dedicated project and dedicated RLS policies.

Shared core — Flutter · Clean Architecture · Arena engine · Design system
Goiás flavorOwn identity, content and data
