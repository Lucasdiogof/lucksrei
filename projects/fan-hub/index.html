Goiás App

An app for Goiás fans, built on Fan Hub, a multi-club Flutter base with independent flavors. Each club gets its own configuration, assets and Supabase project.

Android iOS Web / PWA Flutter Supabase

What fans use

The app in use

Architecture

Fan Hub architecture

The club configuration is injected at startup through the flavor and applies from the domain layer down to the data layer. In Supabase, each club has its own project and dedicated RLS policies.

The base was built to support multiple clubs. The screens and examples on this page show only the Goiás experience.

Fan Hub base — shared core: Flutter · Clean Architecture · Arena engine · Design system
