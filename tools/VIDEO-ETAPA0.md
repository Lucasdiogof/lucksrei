# Vídeos de vitrine — Etapa 0 (fontes e render reproduzível)

Onde está a fonte de cada vídeo publicado em `assets/video/`:

| Vídeo | Fonte | Versionada em |
|---|---|---|
| Aprovaura | `tools/video/aprovaura/` | este repositório |
| Match Queue | `tools/video-match-queue/` | este repositório |
| Bebômetro, OrbiJob, BusãoGyn, StockPort | `tools/video-*/` | este repositório |
| Goiás App | `fan-hub-launch-film/` (`film.html?v=4` = os 27 s publicados) | repositório Git **local**, sem remoto |
| La Pelve | `la-pelve-launch-film/` (= `out/la-pelve-completo-v6-web720.mp4`) | repositório Git **local**, sem remoto |

Os dois filmes de clube/cliente ficam fora deste repositório público porque a pasta `assets/` deles tem fotos de
jogadores, o cartão de sócio e escudos de terceiros (e ~150 MB de saídas e áudio, ignorados).

Tipografia: Aprovaura usa Inter 4.0 estático + Inter Display; Match Queue usa Inter 4.0 variável
(`assets/fonts/`, OFL). O binário exato do render original não é recuperável: ver o relatório da Etapa 0.
