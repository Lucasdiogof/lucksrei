About

Mobile developer, focused on Flutter

I've worked with Flutter since 2019, on Android and iOS apps, using Clean Architecture, tests and BLoC/Cubit. The work doesn't stop at the UI: I also handle backend integration, offline data, flavors, the build pipeline and store releases. I've also been part of migrating native apps to Flutter.

I've worked in fintech, agrotech, government systems and my own products. Before mobile I worked on Java backend and web systems, which helps me think about the app together with the API, the database and the release.
